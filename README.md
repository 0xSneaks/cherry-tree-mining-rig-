# THE CHERRY TREE

<p align="center">
  <img src="docs/assets/cherry-tree-hero.png" alt="The Cherry Tree" width="300">
</p>

THE CHERRY TREE is a Solana-native mining simulation. Users buy non-redeemable rigs, receive a share of a transparently funded SOL reward stream, and may claim rewards or compound them into additional rigs.

The repository contains an Anchor program, a dependency-free Rust accounting engine, and a Next.js application with Cherry integration paths. The checked-in tests report that live deployment, real Cherry handshake, live wallet execution, and some live-chain checks remain unverified in this environment.
