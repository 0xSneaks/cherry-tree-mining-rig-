BUILD & RUN

Deployment

DOCUMENTED INTENT

scripts are devnet-guarded and verify the cluster by genesis hash.

INCOMPLETE / UNCONFIRMED

this worktree does not establish a live deployment.

Safe sequence

  1. run ./scripts/verify.sh
  2. run ./scripts/verify-deploy-ready.sh
  3. build/deploy with ./scripts/devnet-deploy.sh
  4. initialize with ./scripts/devnet-init.sh
  5. fund an explicit schedule with ./scripts/devnet-fund.sh amount duration
  6. then run smoke/rehearsal scripts and inspect read-back checks

Scripts refuse mainnet. Vercel configuration is in app/vercel.json; production hosting, Cherry registration, and production deployment are not verified.

Environment variables

Variables are documented in .env.example and app/.env.example. This package intentionally omits secret values.
